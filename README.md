# Mass & Grass

موقع براند Mass & Grass للمنتجات المرسومة يدوياً بالألوان المائية.

## البنية

| المسار | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `content/site.json` | بيانات عامة: البراند، التواصل، الألوان، الأقسام |
| `content/home.json` | نصوص الصفحة الرئيسية (عربي + إنجليزي) |
| `assets/css/main.css` | الثيم (بيج وألوان طينية) |
| `assets/js/watercolor.js` | محرّك الألوان المائية (الرسم الحي) |
| `assets/js/app.js` | عرض المحتوى، الحركات، اللغة |
| `tools/build_preview.py` | يجمّع الصفحة بملف واحد للمعاينة |
| `docs/` | تحليل الموقع المرجعي ولقطاته |

كل النصوص والأقسام موجودة بملفات `content/*.json`. لتعديل أي نص أو إضافة قسم، عدّل الـ JSON، والصفحة بتقرأه تلقائياً.
كل نص إله نسختين: `{ "ar": "…", "en": "…" }`.

## التشغيل محلياً

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

## الخط

الموقع بيستخدم خط **ثمانية** (Thmanyah Sans + Thmanyah Serif Display) من الحزمة المجتمعية
`@dawod/thmanyah-font-web`. رخصة الخط الرسمية للاستخدام الشخصي، فلازم نتأكد من
إذن الاستخدام التجاري مع ثمانية قبل الإطلاق (Ask@thmanyah.com).
الخطوط الاحتياطية: Amiri و IBM Plex Sans Arabic من Google Fonts.

## الخطوات الجاية

1. تعبئة الصفحة الرئيسية بالمحتوى الحقيقي والصور.
2. بناء صفحات الأقسام واحدة واحدة.
3. لوحة التحكم (`/admin`) لتعديل ملفات `content/` بدون كود.
4. النشر على Cloudflare Pages وربط الدومين.
