# تحليل موقع madeeingaza.com

مرجع لبناء موقع بنفس البنية والحركات لكن بثيم مختلف.
التحليل مبني على ملفات الموقع الفعلية (HTML + CSS + JS) ولقطات شاشة من المتصفح، بتاريخ 2026-09-28.
لقطات الشاشة موجودة في `docs/reference-screenshots/` (`d-` = ديسكتوب 1440px، `m-` = موبايل 390px).

---

## 1. البنية التقنية (Stack)

| البند | التفاصيل |
|---|---|
| نوع الموقع | **موقع ستاتيك مكتوب يدوياً**، بدون فريمورك (لا React ولا Next ولا Shopify ولا WordPress) |
| الملفات | `index.html` واحد + `site.css` (~120KB) + `app.js` (~92KB) + `site-config.js` صغير |
| الاستضافة | **Cloudflare** (Pages غالباً): هيدر `server: cloudflare` + `cf-cache-status` |
| أسماء الملفات | فيها hash للكاش (`site.d6e6df7b0dec.css`)، يعني في build step بسيط |
| مكتبات حركة | **ولا وحدة**. كل الحركات CSS keyframes + transitions + JS خام (`requestAnimationFrame` و`IntersectionObserver`) |
| الصور | كلها `webp`، بأسماء فيها المقاس والـ hash (`img-003-560x688-….webp`) |
| الـ SEO | `og:*` و`twitter:card` و JSON-LD (Organization + WebSite + CollectionPage) و `sitemap.xml` و `robots.txt` و `site.webmanifest` (PWA) |
| التحليلات | سكربت analytics بيتحمّل **بعد** حدث `load` عشان ما يبطّئ الصفحة، و`trackEvent` بيبعث لـ `gtag` لو موجود |

### ⚠️ لوحة التحكم
**ما في لوحة تحكم.** جربت `/admin` و `/dashboard` و `/login` و `/wp-admin` وكلها بترجع 404.
المحتوى كله (المنتجات والطوابع والستيكرات واللوحات) **مكتوب مباشرة جوّا `app.js`** كمصفوفات JavaScript:

```js
const postages   = [{src, ar, en, val, year}, …];
const collections= [{ka, ke, ar, en, dar, den, view, acc, feature}, …];
const STICKERS=[…], STAMPS=[…], CITYD=[…], KEFF=[…], PAINTINGS=[…];
```

وفي تعليق بالكود بيقول: `/* لإضافة طوابعك الحقيقية: حطّ روابط/مسارات الصور هنا */`، يعني أي تعديل على المحتوى بيصير بتعديل الكود.
الإعدادات العامة بملف منفصل `site-config.js`:

```js
window.MIG_CONFIG = { whatsapp: "9725…", defaultLanguage: "ar", siteUrl: "…", gaMeasurementId: "" };
```

**ما في دفع ولا سلة.** كل زر "اطلب" بيفتح واتساب برسالة جاهزة فيها اسم المنتج (شوف القسم 7).
الدعم المالي عن طريق روابط خارجية: Chuffed (تبرعات) و Ko-fi (متجر).

> **توصية لمشروعنا:** لو بدنا لوحة تحكم فعلية، الأنسب نفصل البيانات عن الكود (ملف JSON أو Headless CMS زي Sanity/Strapi/Decap CMS أو Supabase)، ونخلّي نفس الواجهة تقرأ منها. هيك بنحافظ على خفة الموقع الستاتيك وبنقدر نعدّل المنتجات بدون ما نلمس الكود.

## 2. الخطوط (Typography)

الخطوط **مستضافة ذاتياً** (`woff2`) وهي عائلة **ثمانية (Thmanyah)**:

| العائلة | الأوزان | الاستخدام |
|---|---|---|
| **Thmanyah Display** | 400، 700 | العناوين الكبيرة (`.display`، `h1`، `h2`)، والأسماء العملاقة بالخلفية |
| **Thmanyah Sans** | 400، 500، 700 | النصوص والأزرار والقوائم، وكمان للإنجليزي |

```css
--ar-disp:'Thmanyah Display','Aref Ruqaa',serif;
--en-disp:'Thmanyah Display',serif;
--ar-body:'Thmanyah Sans','IBM Plex Sans Arabic',sans-serif;
--en-body:'Thmanyah Sans',system-ui,sans-serif;
```

الخطوط الاحتياطية: Aref Ruqaa للعناوين و IBM Plex Sans Arabic للنصوص.
كل الخطوط محمّلة بـ `font-display:swap`.

**قواعد الطباعة:**
- العناوين: `font-weight:700`، و`line-height:1.28–1.36` للعربي و`1.08` للإنجليزي، مع `text-wrap:balance`.
- حجم الـ h1: `clamp(2.1rem, 5vw, 3.6rem)` تقريباً، يعني حجم مرن حسب عرض الشاشة.
- الـ **Eyebrow** (السطر الصغير فوق العنوان): `.7rem`، `letter-spacing:.34em`، uppercase، ذهبي.
- كلمات مميزة داخل العنوان: `<span class="gold">` لونها ذهبي فاتح، و`<span class="mel">` لونها أحمر بطيخي (مثل "فنٌّ من **غزة** يُروى **بالبكسل**").
- النص الأساسي: `line-height:1.7`، ولون النص الثانوي كريمي بشفافية 62%.

> ⚖️ **ملاحظة ترخيص:** خط ثمانية مجاني بس إله شروط استخدام. لازم نتأكد من الرخصة قبل ما نستخدمه، أو نختار بديل. بدائل مجانية على Google Fonts: **Reem Kufi** أو **Aref Ruqaa** أو **El Messiri** للعناوين، و**IBM Plex Sans Arabic** أو **Readex Pro** أو **Noto Kufi Arabic** للنصوص.

## 3. الألوان (Design Tokens)

ثيم **داكن فقط** (`color-scheme: dark`)، مستوحى من ألوان فلسطين: أخضر داكن كالليل، وذهبي، وأحمر بطيخي.

```css
:root{
  --night:#080C0A;      /* الخلفية الأساسية */
  --night-2:#0D1310;    /* خلفية ثانوية + theme-color */
  --surface:#121C16;    /* الكروت */
  --surface-2:#16221A;
  --cream:#ECE7D9;      /* النص */
  --muted:rgba(236,231,217,.62);
  --faint:rgba(236,231,217,.40);
  --gold:#C9A24B;       /* اللون الرئيسي: أزرار وخطوط */
  --gold-soft:#E4CD92;  /* hover + كلمات مميزة */
  --emerald:#2BB585;
  --emerald-deep:#0E6B4C;
  --watermelon:#E8344E; /* لون التمييز + ::selection */
  --line:rgba(236,231,217,.12);
  --line-gold:rgba(201,162,75,.34);
  --shadow:0 30px 70px -34px rgba(0,0,0,.8);
  --maxw:1180px;
}
```

**الخلفية الجوّية:** طبقة `body::before` ثابتة فيها 3 توهّجات `radial-gradient`: أخضر فوق يمين، وأحمر تحت يسار، وذهبي بالنص، كلها بشفافية 5–10%. هاي هي اللي بتعطي الموقع عمق بدل ما تكون الخلفية سودا مسطحة.

كل مجموعة إلها **لون مميز خاص** بيتمرر كمتغير `--acc` (مثلاً: اللوحات `#C9A24B`، الملابس `#E8344E`، الكوفية `#2BB585`)، وبيستخدم في الحدود والختم والتوهّج باستخدام `color-mix()`.

> **للثيم الجديد:** بنغيّر هدول الـ tokens بس، ومعظم الموقع بيتبع لحاله. كل الألوان معرّفة كمتغيرات.

## 4. التخطيط والتنقل (Layout & Navigation)

### الهيدر (sticky)
1. **الصف الأول:** اللوغو + wordmark (`made.in.gaza`، والنقطة الأولى لونها بطيخي). بعدها روابط الأقسام الست مع خط ذهبي تحت الرابط النشط. وعلى الطرف: رابط "الحكاية" وزر اللغة `EN / ع` وزر "تواصل" الذهبي.
2. **الصف الثاني (utility bar):** "ادعم المشروع" مع pills لـ Chuffed و Ko-fi، وبعدها "تابعنا" مع أيقونات Instagram و Pinterest و X و WhatsApp (SVG inline).
3. **على الموبايل (<860px):** الروابط الرئيسية بتختفي وبتطلع **شريطة chips أفقية قابلة للسحب** (`scroll-snap`). الـ chip النشط بيتعبّى ذهبي، وبيعمل `scrollIntoView` تلقائي للنص.

الخلفية `rgba(8,12,10,.94)` مع خط سفلي رفيع.

### الراوتر (SPA بدون فريمورك)
- كل الصفحات موجودة جوّا `index.html` واحد كـ `<div class="view" id="view-…" hidden>`.
- الروابط `/stickers/` و `/stamps/` وغيرها **روابط حقيقية** (`history.pushState`)، وكل مسار إله ملف HTML نسخة، عشان الـ SEO والمشاركة.
- `popstate` بيدعم زر الرجوع، والروابط القديمة `#stickers` لسا شغالة.
- **Lazy build:** كل view ما بتنبنى (وما بتحمّل صورها) إلا لما تنفتح (`buildActiveView`).
- الحركات التلقائية (سلايدرات) بتشتغل بس بالصفحة الظاهرة، وبتوقف لما التاب مش ظاهر (`document.visibilityState`).

### الفواصل بين الأقسام ("السيم")
SVG خط منقّط ذهبي (`stroke-dasharray:1 10`) **بيتحرك كأنه غرزة خياطة**: `@keyframes stitch` بيحرّك `stroke-dashoffset` بشكل لا نهائي. هاد رمز للتطريز الفلسطيني.

### الفوتر
3 أعمدة: تصفّح، ادعم المشروع (كروت Chuffed/Ko-fi مع سهم ↗)، تابعنا (كروت سوشال).
وتحت سطر فيه السنة (بتتحدث بـ JS) وجملة "من غزة، نصمّم لنُبقي الحكاية حيّة 🍉".

## 5. الصفحات والأقسام بالتفصيل

### 5.1 الرئيسية `/`
| القسم | المحتوى | الحركة |
|---|---|---|
| **Hero** | عنوان كبير بكلمات ملونة، وفقرة، وزرين (ذهبي + ghost)، و3 إحصائيات (19K+ / 2M+ / 100%) | **7 طوابع بريد بتطير من برا الشاشة** وبتستقر بزوايا مائلة (`flyin`)، بعدها بتتمايل (`bob`)، وبتتحرك مع الماوس بعمق مختلف لكل طابع (parallax) |
| **المجموعات** | 6 كروت (`ccard`) مرقّمة 01–06، كل كرت بلونه، وفيها صور مركّبة (ترتيبات: triptych / fan / scatter) مع ختم مائي | عند الـ hover: الكرت بيرتفع، وبيطلع سطر "تصفّح المجموعة →" والسهم بيتحرك |
| **قطعة الأسبوع** | SVG تطريز + وصف + chips (4K, PNG+PDF, ترخيص) + سعر `$18` + زر طلب | reveal |
| **الحكاية (مختصرة)** | لوغو، اقتباس "كنّا هنا. وما زلنا هنا."، فقرتين، توقيع | reveal |

### 5.2 ستيكرات `/stickers/`
- **Hero:** جدار من 12 ستيكر **بتنلزق بحركة 3D** (`slap3d`): بتنزل من فوق مع `rotateY(85deg)` وبتعمل ارتداد صغير (easing `cubic-bezier(.18,.9,.2,1.25)`، القيمة الأخيرة فوق 1 = overshoot). بعدها تمايل مستمر (`sway`) + parallax.
- **Mockups (bento grid):** الستيكرات على شنطة ولابتوب وترمس.
- **المعرض:** 34 ستيكر، وعند الـ hover بيطلع زر "اطلب · اسم الستيكر".

### 5.3 طوابع المدن `/stamps/`
- **Coverflow 3D:** 26 طابع. العنصر النشط بالنص، والباقي بيبعدوا بـ `translateZ(-170px × المسافة)` و`rotateY(-40deg × المسافة)` و`scale` و`opacity` بيقلّوا تدريجياً. بيظهر بس ±3 عناصر، والصور بتتحمّل بس لما تقرّب.
- أزرار ‹ › ونقاط (dots)، وتشغيل تلقائي، وانتقال `.55s cubic-bezier(.2,.7,.2,1)`.
- **Scatter:** الطوابع كصور Polaroid مبعثرة على الحيطان مع parallax.
- حواف الطوابع المسنّنة (perforation) بتنرسم بـ JS (`perforate()`) كدوائر بلون الخلفية، أو بـ CSS `mask` بـ `radial-gradient`.

### 5.4 ملابس "مُدنٌ تُلبَس" `/designs/`
- **Hero "حبل الغسيل":** 8 قمصان معلّقة بمشابك على حبل. كل وحدة بتتمايل (`ctySway`) بسرعة وتأخير مختلفين. القميص النشط بيكبر (`flex-basis` بـ `.75s cubic-bezier(.22,.86,.24,1)`) والباقي بيصيروا رماديين وباهتين.
- **اسم المدينة عملاق بالخلفية** (`cty-ghost`، `font-size` لحد `13.5rem`) بلون المدينة بشفافية 11% + `text-stroke`.
- عداد `02 / 08`، وتبديل تلقائي كل 4.2 ثانية.
- **شبكة المدن:** كروت، وعند الـ hover التصميم بيغمق وبيطلع القميص.
- **Lightbox:** لوحتين جنب بعض (التصميم + القميص).
- أرشيف 10 تصاميم سابقة.

### 5.5 كوفية الأمم `/keffiyeh/`
- **Hero بعرض كامل:** صور لاعبين بكوفيات بألوان المنتخبات، وخلفية نفس الصورة مغبّشة (`blur(32px) brightness(.42)`).
- انتقال **crossfade** (`opacity 1.1s`) + **Ken Burns** (`scale 1→1.05` خلال 7.2 ثانية) + شريط صور مصغّرة، وتبديل تلقائي كل 3.6 ثانية.
- **Keffiyeh wall:** جدار كوفيات، وعند الـ hover "بتنكشف على الجسد"، وفي lightbox مع صور مصغّرة.

### 5.6 لوحات `/paintings/`
- **"الرواق المعلّق":** خيط ذهبي أفقي، واللوحات معلّقة بسلك وخطّاف، وبتتمايل كالبندول (`pgSway` ±1.5deg، `transform-origin:top center`).
- اللوحة بالنص عليها **بقعة ضوء** (spotlight) والباقي باهتين، والانتقال `1.05s`.
- "Salon wall": الـ 10 لوحات معلّقة، مع بطاقة متحف (cartellino) لكل لوحة.
- Lightbox بتصميم متحف.

### 5.7 أعمال جريئة `/concept/`
- **Hero "الدولار المتجمّع":** صورة مقسومة لـ **9×4 = 36 شظية**، بيطيروا بـ 3D (`translate3d` + `rotateX/Y`) وبيتجمعوا من المركز للأطراف (التأخير حسب البعد عن المركز). بعد 1.75 ثانية "بتلتحم" الشقوق مع **موجة صدمة** (`dpShock`)، وبعد 2.5 ثانية بيبلش **لمعان** (`dpSweep`) + طفو + parallax 3D مع الماوس. في زر "أعِد التجميع".
- جدار كولاج بصور مثبتة بـ **شريط لاصق (washi tape)**، بتتمايل عند الـ hover.
- Lightbox الصورة فيه مغبّشة، وفي زر "اضغط مطوّلاً للمعاينة".

### 5.8 الحكاية `/story/`
- افتتاحية: اسمين كبار "بيلا 21 ✕ عبد الرحمن 27".

## 6. الحركات والانتقالات (Motion System)

### 6.1 منحنيات الحركة (Easing)
| المنحنى | الإحساس | وين مستخدم |
|---|---|---|
| `cubic-bezier(.2,.7,.2,1)` | ناعم، ease-out قوي | الكروت، الـ coverflow (**الأساسي**) |
| `cubic-bezier(.2,.8,.2,1)` | نفس الشي أنعم | طيران الطوابع، Polaroid |
| `cubic-bezier(.18,.9,.2,1.25)` | **ارتداد** (overshoot) | لزق الستيكرات |
| `cubic-bezier(.22,.86,.24,1)` | انزلاق طويل | تكبير القمصان |
| `cubic-bezier(.22,.61,.24,1)` | هادي وبطيء | اللوحات المعلّقة |
| `cubic-bezier(.16,1,.3,1)` | expo-out | حركات متفرقة |

### 6.2 المدد (Durations)
- hover صغير (أزرار وروابط): `.18–.25s`
- hover الكروت: `.3–.4s`
- سلايدرات: `.55s` (طوابع)، `.75s` (قمصان)، `1.05–1.1s` (لوحات وكوفيات)
- ظهور عند السكرول: `.8s` (بتصير `.5s` بتعديل لاحق)
- تبديل الصفحات: `.3s` fade
- تمايل مستمر: `4.9–7.2s`، وكل عنصر إله مدة وتأخير مختلفين عشان ما يتمايلوا مع بعض

### 6.3 كل الـ Keyframes
| الاسم | شو بيعمل |
|---|---|
| `stitch` | خط الغرزة المتحرك بين الأقسام |
| `flyin` | الطوابع بتطير وبتستقر (مع scale 1.5 → 1.1 → 1) |
| `bob` / `floaty` / `dpFloat` | طفو عمودي ±9–10px |
| `slap3d` | لزق الستيكر بـ 3D مع ارتداد |
| `sway` / `pgSway` / `ctySway` | تمايل خفيف (±1.2–1.5deg) |
| `pmpress` | ختم بريد بينطبع (scale 1.8 → 1 مع دوران) |
| `dsheen` / `dpSweep` | لمعان ضوئي بيمرّ على السطح |
| `dpShock` | موجة صدمة دائرية |
| `kmarq` | شريط متحرك أفقي (marquee) |
| `kfken` | Ken Burns zoom |
| `cxFade` / `cxRise` | ظهور الـ lightbox (fade + صعود مع scale .965) |
| `pstampIn` | دخول الطابع بدوران |

### 6.4 أنماط متكررة
1. **Scroll reveal:** أي عنصر عليه `.reveal` بيبدأ `opacity:0; translateY(26px)`. الـ `IntersectionObserver` (threshold .12) بيضيف `.in` لما يوصله السكرول، وبيظهر مرة وحدة بس.
2. **تبديل الصفحات:** الصفحة الحالية بتاخد `.leaving` (fade out بـ `.3s`)، بعدها بتنخفى والجديدة بتظهر بـ fade in، وبيصير scroll للأعلى بشكل ناعم.
3. **Parallax بالماوس:** loop واحد بـ `requestAnimationFrame` مع throttling. كل عنصر إله `data-depth`، والإزاحة = `(موقع الماوس − 0.5) × depth × 24px`.
4. **نقطة مؤشر ذهبية** (`cursor-dot`، 7px) بتلحق الماوس. بس بتطلع على الأجهزة اللي فيها ماوس، ومش بوضع perf-lite.
5. **العشوائية المتحكَّم فيها:** زوايا البداية ومدد التمايل بتتولّد بـ `Math.random()` ضمن مدى محدد، عشان الحركة تبين طبيعية.
6. **متغيرات CSS لكل عنصر:** (`--d`، `--r`، `--fromx`، `--sw`…) بتتحط من JS، والحركة نفسها كلها بالـ CSS.

### 6.5 الأداء وإمكانية الوصول
- **`perf-lite`:** لو الجهاز ضعيف (≤8 cores أو ≤6GB RAM) أو في Save-Data أو الشاشة ≤900px، بتتوقف الحركات الثقيلة والمؤشر والغرزة.
- **`motion-paused`:** أي مشهد متحرك بيطلع برا الشاشة، حركته بتتوقف (`animation-play-state:paused`).
- **`prefers-reduced-motion`:** بيوقف التشغيل التلقائي والـ parallax والتمايل.
- Lazy images بـ `data-src` + `IntersectionObserver` (rootMargin 320px)، و`preload` لصورة الـ hero الأساسية.
- Skip link، `aria-label`، `aria-current`، و`<noscript>` برسالة ورقم واتساب.

## 7. الطلب والتواصل (WhatsApp flow)

أي عنصر عليه `data-wa` و `data-product="اسم المنتج"` بيفتح:

## 8. تعدد اللغات (AR / EN)

- اللغة الافتراضية عربي مع `dir="rtl"`.
- كل نص بالـ HTML إله نسختين: `data-ar="…"` و `data-en="…"`. زر اللغة بيلفّ على كل العناصر وبيبدّل المحتوى (`innerHTML` لو فيه وسوم، وإلا `textContent`).
- بيتغير `lang` و`dir` و`title` و`meta description`، وبيتبدّل class الـ body (`lang-ar` / `lang-en`) عشان الخطوط و`letter-spacing` يتعدلوا.
- الـ CSS بيستخدم **logical properties** (`inset-inline-start`، `padding-inline`، `margin-inline-end`)، فالتخطيط بينقلب لحاله بين RTL و LTR.
- ⚠️ اللغة **مش محفوظة** (لا localStorage ولا URL)، يعني بترجع عربي مع كل تحميل.

## 9. حماية الصور
- `contextmenu` و `dragstart` ممنوعين على الصور، و`draggable="false"`.
- **علامة مائية مزدوجة:** شبكة نص `made.in.gaza` متكررة (`wm-net`، `mix-blend-mode:soft-light`) + **ختم دائري** منقّط (`wm-seal`) فيه اسم القطعة، بلون المجموعة.
- الصور المعروضة صغيرة (560px)، والملفات الأصلية بتنبعث بعد الطلب.

## 10. الـ Responsive
- Breakpoints كثيرة (390 → 1180px)، أهمها **860px**: عنده بتختفي روابط الهيدر وبتطلع الـ chips.
- على الموبايل: الـ hero بيصير عمود واحد والصورة فوق النص، وبعض العناصر بتختفي (`.m-hide`)، والـ Polaroids بتصير static، والـ lightbox بيصير عمود واحد.
- أحجام الخطوط والمسافات كلها بـ `clamp()`.
